## 3. 검색 순위와 문서 지표의 독립 검산

| 방식 | 독립 검산 방법 | 결과 |
| --- | --- | --- |
| C0 키워드 | PostgreSQL에서 영어 전문 검색과 `ts_rank_cd`를 직접 실행 | 500개 질문 모두 상위 후보 청크의 순서와 점수 일치 |
| C1 벡터 | NumPy로 각 질의와 청크 벡터 1,248개 사이의 코사인 유사도를 전수 계산 | 500개 질문 모두 상위 50개 순서 일치. 최대 점수 차이 약 1.44 × 10⁻⁷ |
| C2 하이브리드 | C0·C1 후보를 청크 ID로 합치고 각 구성 검색기 순위에 대해 `1 / (60 + 순위)`를 합산 | 500개 질문 모두 상위 50개 청크, 구성 순위, 결합 점수 일치 |

문서 지표도 앱의 평가 함수를 호출하지 않고 계산했다. 각 청크를 DB의 부모 문서 ID로 변환하고 첫 등장 순서로 문서를 중복 제거했다. Recall@k는 상위 k개 고유 문서에서 찾은 정답 수를 해당 질문의 전체 정답 수로 나눴다. MRR은 첫 정답 문서 순위의 역수를 평균했고, 정답을 찾지 못한 질문에는 0을 적용했다.

예를 들어 Google Cloud Marketplace 구독 권한 반영 지연을 묻는 `qst_0004`의 정답 문서 `dsid_6c4c1c875e704f09b4d791d64d7bc7e5`는 C0에서 1위, C1에서 3위, C2에서 1위였다. 이 질문의 C1 Recall@1은 0, Recall@5는 1, 역순위는 1/3으로 저장된 값과 일치했다. [독립 검산 결과](results/recheck-20261121T022649Z-aWjsEw/evaluation-audit.json)
